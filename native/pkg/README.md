# Orbis Store Native package layout

A build instalavel precisa conter:

- eboot.bin
- sce_sys/param.sfo
- sce_sys/icon0.png (512x512, PNG 24-bit, sem alpha)

Metadados planejados:
- Title: Orbis Store
- Title ID: BREW00001
- Content ID: IV0000-BREW00001_00-ORBISSTORE000001
- Version: 01.00
- Type: gd (Game Digital Application)

O PKG final deve ser produzido por uma ferramenta de empacotamento compativel com homebrew PS4. Nao renomeie ZIP/ELF para PKG.
