Como instalar

  1. Baixe o PKG pelo celular ou computador.
  2. Copie o arquivo para um pendrive compatível ou transfira para o PS4 com seu cliente de arquivos.
  3. Feche a Peppy e instale o PKG pelo instalador do seu PS4 desbloqueado.

O navegador do PS4 pode recusar o download deste tipo de arquivo. Este arquivo é um PKG; abrir o link não envia um payload ao GoldHEN.

Se o download não abrir, use a página da release e selecione o arquivo .pkg.

As funções de premium, conta, LivePix e administração ficam dentro do aplicativo Peppy Store.
